AWS LLMjacking Detection Lab

A purple team lab that simulates LLMjacking — attackers using stolen cloud credentials to run expensive AI models on someone else's bill — and builds the detections to catch it.

  • Terraform
  • Sigma
  • Amazon Bedrock
  • MITRE ATT&CK

Write-ups

  1. Week 0 Building a lab that is safe to attack Identity separation, no long-lived access keys, offline secrets, cost guardrails
  2. Week 1 Giving the lab eyes CloudTrail, S3 log storage and Bedrock invocation logging, all in Terraform
  3. Weeks 2–3 Simulating the attack Stratus Red Team against my own account, mapped to MITRE ATT&CK
  4. Weeks 3–5 Detection as code Sigma rules with test fixtures, validated in CI
  5. Week 6 Automated response Quarantining a compromised credential, with cost anomaly detection as a backstop
  6. Weeks 7–8 Publishing the work Documentation, an article, and a rule proposed upstream to SigmaHQ

Source, Terraform and detection rules: github.com/yamekuro/aws-llmjacking-detection-lab

Everything here runs against a dedicated lab account. No third-party systems are touched.
